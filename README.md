# Lay's Gourmet — Luxury Scrollytelling Web Experience

An ultra-luxury, high-performance interactive scrollytelling web experience showcasing Lay's Gourmet artisanal potato chips.

## ✨ Key Features
- **Scrollytelling Hero:** Frame-by-frame 210-image canvas sequence mapped to scroll progress.
- **Flavor Anatomy Grid:** Interactive deep-dive into handcrafted spice blends and seasoning profiles.
- **Ingredient Provenance:** Visual journey of locally sourced, hand-picked ingredients.
- **Nutritional Architecture:** Detailed, beautifully formatted nutrition breakdown.
- **Notch Navbar:** iOS dynamic-island inspired floating navigation bar with quick links and actions.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** Framer Motion, HTML5 Canvas
- **Icons:** Lucide React
- **Language:** TypeScript

## 🚀 Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
